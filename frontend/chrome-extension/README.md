# Chrome Add to saved

The desktop app copies this extension to a stable folder at `%LOCALAPPDATA%\InternshipHubData\chrome-extension` when it starts. In Chrome, open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select that folder. Pin **Internship Hub — Add to saved** to the toolbar.

On a company application page, click the extension and choose **Review in Internship Hub**. Chrome may ask whether to open Internship Hub. The desktop app opens an editable form; nothing is saved until you choose **Add opportunity**. The extension requests access only to the tab where you click it. If page metadata is unavailable, enter the title and company yourself.

Chrome Web Store distribution and automatic extension installation are later work.
